# Pet Shop — 10 Componentes Funcionais em React

Projeto acadêmico para a atividade do 2º ADS.

## Tecnologias
- React
- Vite
- JSX
- CSS

## Os 10 componentes
1. Header
2. Hero
3. ServiceCard
4. ProductCard
5. UserCard
6. PetForm
7. ContactForm
8. Counter
9. ThemeToggle
10. TodoList

## Como executar

```bash
npm install
npm run dev
```

Depois, abra o endereço informado pelo Vite no navegador.

## Observação
Este projeto demonstra componentes funcionais React com retorno JSX, props, useState, eventos e renderização de listas.
